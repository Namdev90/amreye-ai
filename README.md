# OpenAI Device Manager — verification staging

Community Windows preview-first maintenance tool. This isolated branch is not AMReye.AI application code. Do not merge it into main.

The initial source archive is split into integrity-checked segments. The Windows verification workflow reconstructs it, runs offline regression tests under Windows PowerShell 5.1 and PowerShell 7, constructs the GUI without installing software, then publishes the readable source on this branch only.

No laptop maintenance has been run by publishing this branch. No account secrets or personal diagnostic reports are included.
