# Contributing

AMReye.AI is a research and prototype project. Contributions should preserve the distinction between current prototype behavior, proposed product capability, and future research.

Before opening a pull request:

1. Keep claims supported by the source register or label them as proposed or future work.
2. Run the relevant tests for the area changed. For a broad change, run `npm test`.
3. Check keyboard access, focus visibility, mobile layouts, and offline behavior when UI or runtime code changes.
4. Do not commit credentials, private laboratory data, local toolchains, build caches, APKs, or generated secrets.
5. Explain the user-facing result, validation performed, and any evidence or limitation that remains.

Use a focused branch and a descriptive commit message. Keep unrelated formatting or refactoring out of the pull request.
